# Вопрос

Расскажите, чем отличаются команды: `t.sh`, `. t.sh`, `/t.sh`, `./t.sh`?

[English version](index.md) | [Все вопросы](../../README.ru.md)

---

## Краткий ответ

`t.sh` ищет в директориях PATH; `. t.sh` выполняет скрипт в текущей оболочке; `/t.sh` выполняет из корня файловой системы; `./t.sh` выполняет из текущей директории.

---

## Подробное объяснение

Эти четыре [команды](https://ru.wikipedia.org/wiki/Команда_(программирование)) представляют разные способы [выполнения](https://ru.wikipedia.org/wiki/Выполнение_программы) [shell-скрипта](https://ru.wikipedia.org/wiki/Сценарий_командной_оболочки) в [Unix-подобных](https://ru.wikipedia.org/wiki/Unix-подобная_операционная_система) [операционных системах](https://ru.wikipedia.org/wiki/Операционная_система).

### 1. `t.sh` - поиск в PATH и выполнение

Когда вы вводите `t.sh` без указания [пути](https://ru.wikipedia.org/wiki/Путь_к_файлу), [оболочка](https://ru.wikipedia.org/wiki/Командная_оболочка_Unix) ищет этот [файл](https://ru.wikipedia.org/wiki/Компьютерный_файл) во всех [директориях](https://ru.wikipedia.org/wiki/Каталог_(файловая_система)), перечисленных в [переменной окружения PATH](https://ru.wikipedia.org/wiki/PATH_(переменная)). Скрипт выполняется в новом [дочернем процессе](https://ru.wikipedia.org/wiki/Дочерний_процесс) ([подоболочке](https://ru.wiktionary.org/wiki/подоболочка)).

**Основные характеристики:**
- Поиск в директориях из [PATH](https://ru.wikipedia.org/wiki/PATH_(переменная))
- Создается новый [процесс](https://ru.wikipedia.org/wiki/Процесс_(информатика))
- [Переменные](https://ru.wikipedia.org/wiki/Переменная_(программирование)) и изменения [окружения](https://ru.wikipedia.org/wiki/Переменная_окружения) не влияют на родительскую оболочку
- Требуется, чтобы скрипт находился в одной из директорий PATH

### 2. `. t.sh` - команда source (точка)

[Команда точка](https://en.wikipedia.org/wiki/Dot_(command)) (`.`) также известна как [команда `source`](https://ru.wiktionary.org/wiki/source) в [Bash](https://ru.wikipedia.org/wiki/Bash). Она [выполняет](https://ru.wikipedia.org/wiki/Выполнение_программы) скрипт в **контексте текущей оболочки**, а не в подоболочке.

**Основные характеристики:**
- Выполняется в текущей [сессии оболочки](https://ru.wiktionary.org/wiki/сессия)
- Новый процесс не создается
- Переменные, [функции](https://ru.wikipedia.org/wiki/Подпрограмма) и изменения директории сохраняются после выполнения
- Обычно используется для [конфигурационных файлов](https://ru.wikipedia.org/wiki/Конфигурационный_файл) и настройки окружения
- Скрипт не требует [прав на выполнение](https://ru.wikipedia.org/wiki/Права_доступа_к_файлам)

### 3. `/t.sh` - абсолютный путь от корня

Это использует [абсолютный путь](https://ru.wikipedia.org/wiki/Путь_к_файлу#Абсолютный_и_относительный_путь), начинающийся с [корневой директории](https://ru.wikipedia.org/wiki/Корневой_каталог) (`/`) [файловой системы](https://ru.wikipedia.org/wiki/Файловая_система).

**Основные характеристики:**
- Выполняет файл, расположенный по пути `/t.sh` (в корневой директории)
- Создается новый процесс (подоболочка)
- Требует, чтобы скрипт имел [права на выполнение](https://ru.wikipedia.org/wiki/Права_доступа_к_файлам) (например, установленные командой [`chmod +x`](https://ru.wikipedia.org/wiki/Chmod))
- Путь не зависит от текущей [рабочей директории](https://ru.wikipedia.org/wiki/Текущий_каталог)
- Редко используется на практике, так как скрипты обычно не хранятся в корневой директории

### 4. `./t.sh` - относительный путь от текущей директории

Это использует [относительный путь](https://ru.wikipedia.org/wiki/Путь_к_файлу#Абсолютный_и_относительный_путь), где `.` означает [текущую директорию](https://ru.wikipedia.org/wiki/Текущий_каталог).

**Основные характеристики:**
- Выполняет скрипт в текущей рабочей директории
- Создается новый процесс (подоболочка)
- Требует прав на выполнение
- Самый распространенный метод запуска скриптов, не находящихся в PATH
- Префикс `./` явно указывает оболочке искать файл в текущей директории

### Сравнительная таблица

| Команда | Тип пути | Новый процесс | Нужны права exec | Изменения сохраняются | Типичное применение |
|---------|----------|---------------|------------------|-----------------------|---------------------|
| `t.sh` | Поиск в PATH | Да | Да | Нет | Системные команды |
| `. t.sh` | Текущая/PATH | Нет | Нет | Да | Конфиг. файлы |
| `/t.sh` | Абсолютный | Да | Да | Нет | Корневая директория |
| `./t.sh` | Относительный | Да | Да | Нет | Локальные скрипты |

### Примечание о безопасности

В целях [безопасности](https://ru.wikipedia.org/wiki/Компьютерная_безопасность) текущая директория (`.`) обычно **не** включается в переменную PATH на Unix-подобных системах. Это предотвращает случайное выполнение [вредоносных скриптов](https://ru.wikipedia.org/wiki/Вредоносная_программа), размещенных в текущей директории с именами, совпадающими с именами обычных команд.
